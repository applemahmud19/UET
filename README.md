# Admission Roadmap — University Exam Tracker

## GitHub + Vercel e live kora
1. GitHub e notun repository banao.
2. Ei folder-er shob file repository root-e upload koro:
   `index.html`, `sw.js`, `manifest.json`, `vercel.json`, `icon-192.png`, `icon-512.png`
3. Vercel-e repository import koro. Build command lagbe na (static site), Deploy chapo.
4. Deploy hoye gele HTTPS link-ta phone-er Chrome-e ekbar online-e kholo.

## Install
- Android Chrome: Account tab-er "অ্যাপ ইনস্টল করো" button, ba browser menu -> Install app.
- iPhone: Safari -> Share -> Add to Home Screen.

## Offline
- Ekbar online-e khola hole app ar tar data internet chhara-o chole.
- Plan/exam add ba edit korle seta sathe sathe ei phone-e save hoy (offline-eo).

## Code update (auto)
- GitHub-e notun code push korle Vercel nijei deploy kore.
- Phone-e app online-e khulle (ba background theke fire ele) nijei notun version namay ar ekbar reload hoy.
- Kono version number bodlate hoy na.
- Phone-er save kora data update-e muchhe jay na.

## Note
- Data ar account shudhu oi phone/browser-e thake (Local Storage). Alada device-e nite Account tab theke Export/Import koro.
